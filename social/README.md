# VALDA social posts

Editorial template shared by every post: `editorial.css` (Fraunces display serif, Inter Tight text, warm paper / espresso palette, hairline rules, lowercase tracked labels). Fonts live in `fonts/`.

Each post folder has `carousel.html` (one `<section class="slide">` per frame), `render.mjs` (run `node render.mjs` in the folder to export 1080 x 1080 PNGs and a PDF) and `caption.md`.
