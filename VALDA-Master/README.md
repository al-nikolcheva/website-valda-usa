# VALDA master folder

Everything needed to brief a printer, agency, journalist or web developer.

| Folder | What's inside | Use it for |
|---|---|---|
| `01-Logo/SVG` | Vector logos | Website, Figma, Canva, anything digital |
| `01-Logo/EPS`, `01-Logo/PDF` | Vector logos for print. Illustrator opens both, so these stand in for `.ai` | Printers, sign makers, embroidery, vehicle wraps |
| `01-Logo/PNG` | Transparent logos at 2000 px and 500 px | Word, PowerPoint, email signatures, social media |
| `01-Logo/Favicon` | `favicon.ico` plus app icons (32, 180, 192, 512 px) | Browser tab and home-screen icons |
| `02-Colours-and-Fonts` | `VALDA-Colours-and-Fonts.pdf` (HEX, RGB, CMYK, Pantone) and the font files (Inter, Inter Tight) | Matching colours and type |
| `03-Catalogue` | 2026 product catalogue and technical catalogue (PDF) | Sending to clients and architects |
| `04-Brand-Guidelines` | `VALDA-Brand-Guidelines.pdf`, 12 pages | How to use the logo, colours, type, imagery, tone |
| `05-Video` | Factory film (1080p, 720p) and the short website loop (MP4) | Website, social, presentations, trade shows |

## Logo versions

Four lockups, each in three colourways:

- **Lockups:** `stacked` (the primary logo), `horizontal`, `icon`, `wordmark`
- **Colourways:** `colour` (blue icon, ink wordmark), `black`, `white`

File names follow `VALDA-logo-<lockup>-<colourway>`, e.g. `VALDA-logo-horizontal-white.svg`.

## Fonts

- **Inter Tight**: the website
- **Inter**: catalogues, print and documents
- **Fallback** (Word, email): Arial

Both are free (SIL Open Font License). The files are in `02-Colours-and-Fonts/Fonts`.

## Rebuilding

Everything here is generated by `scripts/build-master-folder.py`:

```bash
pip install cairosvg reportlab pillow
python3 scripts/build-master-folder.py          # rebuild the folder
python3 scripts/build-master-folder.py --zip    # also write VALDA-Master.zip
```

The catalogue PDFs and films are copied in from `public/` when you run it and are not committed a second time.
